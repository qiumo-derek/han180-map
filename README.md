# 汉末十三州地图

[打开地图](https://qiumo-derek.github.io/han180-map/) · [县界 JSON](https://qiumo-derek.github.io/han180-map/县界数据.json)

十三州分色、州郡边界与荆州等已标记 POI 的圆润分区。共 13 州、102 个郡级图形、145 个 POI 分区。

县界是依据工程边界和 POI 生成的待考据初分，不代表已经考证完成的公元 180 年真实县界。详见 [考据与交付说明](考据与交付说明.md)。

此仓库仅保存可公开的静态成品。GitHub Pages 从 main 分支根目录发布。
